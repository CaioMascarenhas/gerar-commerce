# Referências iniciais

Fontes consultadas para o desenho e a implementação inicial em 04/11/2026:

- Enunciados e modelos de relatório das disciplinas, disponibilizados em `projeto_docs`.
- [Angular — compatibilidade de versões](https://angular.dev/reference/versions). Compatibilidade validada também pelos peerDependencies das versões fixadas no lockfile.
- [NestJS — documentação oficial](https://docs.nestjs.com/).
- [NestJS — microsserviços](https://docs.nestjs.com/microservices/basics). A família usa serviços HTTP independentes; o módulo de transportes de mensagens do Nest não é obrigatório nesta versão.
- [Mastra — agentes](https://mastra.ai/docs/agents/overview).
- [Mastra — ferramentas](https://mastra.ai/docs/agents/tools).
- [GitHub — API para Projects](https://docs.github.com/en/issues/planning-and-tracking-with-projects/automating-your-project/using-the-api-to-manage-projects).
- [Conventional Commits 1.0.0](https://www.conventionalcommits.org/pt-br/v1.0.0/).

Versões fixadas: Angular 22.2.4, Angular CLI/build 22.2.6, NestJS 12.3.3, Mastra Core 1.82.0, TypeScript 6.0.3 e Node.js 24. O identificador Gemini é configurável para usar um modelo realmente disponível na conta da equipe.

Antes dos relatórios finais, formatar as referências conforme a orientação docente e acrescentar os materiais do Classroom efetivamente consultados.
